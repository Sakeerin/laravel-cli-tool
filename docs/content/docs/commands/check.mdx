---
title: check
description: Check Laravel project health — environment variables, security advisories, configuration, and queue setup.
---

## Usage

```bash
lx check [options]
```

## Options

| Option | Description |
|---|---|
| `--fix` | Show recommended fix commands (does not auto-fix) |

## Example

```bash
lx check --fix
```

──────────────────────────────────────────────────

Fix suggestions:
  Add QUEUE_CONNECTION=redis to your .env file

## Checks Performed

| Category | Check |
|---|---|
| Environment | PHP version vs `composer.json` `require.php` |
| Environment | `.env` keys vs `.env.example` |
| Security | `composer audit` for known CVEs |
| Configuration | `APP_KEY` is set |
| Configuration | `APP_DEBUG` is `false` in production |
| Configuration | `APP_ENV` value |
| Queue | `QUEUE_CONNECTION` is not `sync` in production |

## Configuration

Add custom required env keys and warnings to `.lxconfig.yml`:

```yaml
check:
  required_env:
    - APP_KEY
    - DB_CONNECTION
    - REDIS_URL
  warn_if:
    - key: QUEUE_CONNECTION
      value: sync
      message: "Use redis or database in production"
```
