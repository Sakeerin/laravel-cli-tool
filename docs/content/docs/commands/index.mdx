## Free Commands

| Command | Description |
|---|---|
| [`make:service`](/docs/commands/make-service) | Generate a Service class |
| [`make:repository`](/docs/commands/make-repository) | Generate a Repository class |
| [`make:dto`](/docs/commands/make-dto) | Generate a Data Transfer Object |
| [`make:action`](/docs/commands/make-action) | Generate an Action class |
| [`make:module`](/docs/commands/make-module) | Generate an entire module in one shot |
| [`lint`](/docs/commands/lint) | Lint PHP files for convention violations |
| [`check`](/docs/commands/check) | Check project health |
| [`config:init`](/docs/commands/config-init) | Create `.lxconfig.yml` interactively |
| [`config:pull`](/docs/commands/config-pull) | Download a shared config from a URL |
| [`license:activate`](/docs/commands/license) | Activate a Pro license key |
| [`license:status`](/docs/commands/license) | Show current license status |
| [`self-update`](/docs/commands/self-update) | Update `lx` to the latest version |

## Pro Commands (AI)

> Requires an active [Pro license](/pricing) and `ANTHROPIC_API_KEY` in your environment.

| Command | Description |
|---|---|
| [`ai:migration`](/docs/commands/ai/migration) | Generate a migration from a plain-text description |
| [`ai:fix`](/docs/commands/ai/fix) | Analyse an error message and suggest a fix |
| [`ai:test`](/docs/commands/ai/test) | Generate Pest/PHPUnit tests from a class method |
| [`ai:review`](/docs/commands/ai/review) | Review staged or uncommitted code changes |
| [`ai:usage`](/docs/commands/ai/usage) | Show monthly token and cost summary |
