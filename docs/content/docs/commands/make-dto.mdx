---
title: make:dto
description: Generate a Data Transfer Object (DTO) class.
---

## Usage

```bash
lx make:dto {Name} [options]
```

## Options

| Option | Description |
|---|---|
| `--readonly` | Make the class `readonly` (PHP 8.2+) |
| `--from-array` | Add a static `fromArray()` factory method |

## Examples

```bash
lx make:dto CreateUserData --readonly --from-array
```

### Output

```
✓ app/Data/CreateUserData.php
```
